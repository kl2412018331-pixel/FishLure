ADMIN QUICK GUIDE

Manage FishLure

The dashboard controls the public fish and lure catalog, recommendation rules, and user feedback. Changes save to the website database.

Open the dashboard

  1. Sign in on the FishLure homepage with an account that has administrator access.
  2. Admin accounts open the dashboard after sign-in. You can also open admin.html while signed in.
  3. If your account is not recognized as an administrator, ask the site owner to grant access.
  4. Use Log out when finished, especially on a shared computer.
Protect the site: give admin access only to trusted people. Do not share passwords or database credentials.

Search and sort entries

Use the search box in Fish species, Lure styles, or Fish recommendations. Results filter as you type. Use Sort by to choose alphabetical order or Recently added.

Manage fish species

  1. Open Fish species and select Add fish, or choose Edit on an existing row.
  2. Enter a unique Species ID, common name, habitat group, habitat information, and usual depth zones.
  3. Select Save fish. A Species ID cannot be changed when editing a fish.

Manage lure styles

  1. Open Lure styles and select Add lure or Edit.
  2. Enter the lure name and description. Add size, depth zones, suitable environments, colors for clear/stained/murky water, suggested technique, retrieve method, and the reason it may work.
  3. Select Save lure. Use clear descriptions because anglers may see this guidance on the public site.

Manage fish recommendations

  1. Open Fish recommendations and select Add rule or Edit.
  2. Choose a fish and lure, then enter the recommended depth and explanation.
  3. Set the display rank. Smaller numbers appear earlier in the list.
  4. Select Save recommendation and confirm the rule appears in the table.

Review reports and feedback

Open Reports & feedback to read user messages. Change a report status to New, Reviewed, or Resolved, then select Save status.

Delete carefully

  • Deleting a lure also removes recommendation rules that use it.
  • Deleting a fish also removes its recommendation rules. Fish with catch-log entries cannot be deleted.
  • Read the confirmation message before approving a deletion.

If something goes wrong

  • Dashboard access denied: sign in with an admin account or ask the site owner for access.
  • Save fails: complete required fields, use a unique ID, and try again.
  • No search results: clear the search or try a shorter phrase.
  • Database/server error: ask the site owner to check PHP and database availability.
